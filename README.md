# Real Estate React Website

Live Demo: https://reliable-pavlova-787082.netlify.app/

## Project Overview

This is a responsive real estate website built with React.
Users can explore available properties, view property details, and learn about the services provided by the real estate company.

The goal of this project was to practice building modern frontend applications using React and reusable components.

## Features

* Property listings
* Property details page
* Services section
* Testimonials section
* Responsive design
* Smooth animations using Framer Motion

## Technologies Used

* React
* Vite
* Tailwind CSS
* React Router
* Framer Motion


## Future Improvements

* Add property filtering and search
* Add contact form functionality
* Connect the project to a backend database.
